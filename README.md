# 무인도 표류 3D

**시작 캐릭터 선택** — 시작 설정 화면의 기본 캐릭터는 탐험가이며, 캐릭터 목록도 탐험가가 첫 번째로 표시됩니다. 역할별 특성 및 해금 조건은 그대로 유지됩니다.


텍스트 어드벤처 `무인도 표류`를 **Three.js 3D 월드**로 옮긴 버전입니다.
게임 규칙·확률·시나리오는 이전과 같이 **서버(`game-core.js`)에서만 실행**되고,
브라우저는 서버가 보내 준 "지금 상태"를 3D로 그리고 입력을 전달하기만 합니다.

## 실행

```bash
node server.js            # 기본 포트 3000 (PORT=3001 node server.js 로 변경)
# 브라우저: http://localhost:3000
```

- Node.js 18 이상, 외부 패키지 설치 불필요 (`public/vendor/`에 Three.js r170이 들어 있어 인터넷 없이 동작)
- WebGL이 되는 최신 브라우저(Chrome/Edge/Firefox/Safari) 필요
- 느린 기기에서는 프레임이 낮으면 자동으로 해상도·그림자를 낮춥니다. 직접 지정: `?q=0`(가벼움) `?q=1` `?q=2`(최고)

## 폴더 구조

```
island-3d/
├─ server.js            HTTP 서버 · 플레이어별 세션 · SSE 스트림 · 저장소(data/)   (서버 전용)
├─ game-core.js         게임 로직 전체 — 규칙·확률·시나리오·점수·엔딩            (서버 전용, 브라우저로 전송 안 됨)
├─ test-bot.js          무작위 봇이 서버 로직을 끝까지 플레이해 오류를 찾는다 (npm test)
├─ test-cold-boar-balance.js  추위 대응·멧돼지 피해·점수 비노출 규칙 회귀 검사
├─ package.json / README.md / 실행방법.txt
└─ public/              브라우저로 전달되는 파일만 들어 있다
   ├─ index.html        3D 캔버스 + HUD/로그/선택지/시작 전 설정 오버레이
   ├─ styles.css        UI 스타일 (유리 패널, 웨이포인트, 반응형)
   ├─ vendor/three.module.min.js
   └─ js/
      ├─ main.js        진입점: 서버 이벤트(SSE) 수신 → UI(HUD·로그·선택지·결말·저장)와 3D에 반영
      ├─ game3d.js      렌더러·카메라·월드·플레이어 조립, 상태→장면 반영, 웨이포인트, 자동 화질
      ├─ world.js       3D 월드: 지형·바다·하늘·식생·장소 표식·낮/밤/날씨/물때·모닥불·은신처·뗏목·구명보트·멧돼지
      ├─ player.js      아바타 · 키보드/마우스/터치 입력 · 카메라 리그(3인칭/탑뷰/1인칭/궤도)
      └─ audio.js       WebAudio 효과음
```

## 조작법

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (Shift: 달리기) |
| 마우스 드래그 / 터치 드래그 | 시점 회전 (1인칭에서는 둘러보기) |
| 휠 | 확대·축소 |
| Q / R | 카메라 좌우 회전 |
| **V** (또는 상단 `시점` 버튼) | 3인칭 → 탑뷰 → 1인칭 전환 |
| 땅 클릭/탭 | 그곳으로 걸어가기 |
| 주황 **빛기둥** 클릭, 화면 가장자리의 `밀림 25m` 표 클릭 | 그 장소까지 걸어간다 |
| 지도(왼쪽 패널)의 장소 클릭 | 3D 화면의 내가 그 장소까지 길을 따라 걸어간다 |
| 빛기둥 근처에서 **E** | 그 장소로 즉시 이동 요청 |

**장소 메뉴와 이동** — 메뉴는 3D 화면에서 내가 서 있는 위치로 정해집니다.
- 장소(빛기둥 반경 안)에 서 있을 때만 그 장소의 메뉴("무엇을 할까?")가 보입니다. 장소 밖으로 걸어 나가면 메뉴가 숨겨집니다.
- 장소 메뉴 하단의 **`어디로 갈까?`** 아래에서 `→ ○○ 이동`을 고릅니다. 이동 장소는 한 줄에 최대 4개까지 표시됩니다. **발견한 모든 장소**(동굴·절벽 포함)가 어느 장소에서든 나오며, 길이 이어져 있지 않으면 밀림을 거쳐 걷습니다. (`이곳에서 계속한다`는 없어졌습니다.)
- 밀림에서 **`발자국을 따라간다`**를 고르면 "들어갈까?" 질문 없이 곧바로 동굴에 도착해 동굴 메뉴(`동굴에서…`)가 열립니다. 밀림에서 동굴까지 이어진 발자국은 3D 월드의 흙길 위에 찍혀 있습니다.
- 직접 걸어서 다른 장소 안에 들어가 **멈춰 서면** 그 장소에 도착한 것으로 보고 이동이 처리됩니다(지나가기만 하면 처리되지 않습니다). 지도 클릭도 같은 방식입니다.
- 서로 이어지지 않은 장소(예: 해변 → 절벽)로 가면 길(밀림)을 거치는 만큼 허기·갈증이 듭니다.
- 지도의 내 위치 표시는 3D 위치를 그대로 따라 움직입니다.
- 멧돼지 조우 등 사건 선택지는 장소 안에 서 있지 않아도 표시됩니다. 난이도·역할은 게임 시작 전 설정 화면에서 선택합니다.

**화면 구성** — PC: 왼쪽에 정보 패널(위~아래), 오른쪽 위에 상태 HUD, 아래쪽에 이야기·선택 패널(왼쪽 패널 옆에서 오른쪽 끝까지). 모바일: 위 HUD(수치 2×2 + 버튼 3열) · 아래 이야기·선택 패널 · `정보 패널` 버튼으로 여는 시트.

**시작 전 설정** — 새 생존을 누르면 타이틀 화면에서 이름·난이도·표류 전 역할을 먼저 선택합니다. 설정을 완료해야 플레이 화면으로 넘어갑니다. 역할 중 일부는 엔딩 기록으로 해금됩니다.

**게임 종료 절차** — 플레이 화면 오른쪽 위의 `게임 종료`를 누르면 확인 창이 열립니다. `계속 플레이`는 게임으로 돌아가고, `저장 후 종료`는 저장 슬롯을 선택한 뒤 저장하고 타이틀 화면으로 이동합니다(기존 슬롯을 고르면 덮어쓰기 확인). `저장하지 않고 종료`는 저장하지 않은 진행을 버리고 타이틀 화면으로 이동합니다. 브라우저 탭 자체는 닫히지 않습니다.

**소지품 사용** — `아이템 사용 / 상태 확인` 별도 메뉴는 없습니다. 행동 메뉴가 열린 동안 왼쪽 `소지품`의 아이템을 클릭하면 사용·읽기·살펴보기 이벤트가 발생합니다. 물병·유리병·바나나는 즉시 사용되고, 구급상자는 행동력을 소모하며, 낡은 일기장은 눌러 읽을 때마다 다음 페이지가 열립니다. `생존 수첩`은 소지품에 기본 포함되며 클릭하면 아직 확인하지 않은 생존 힌트를 보여 줍니다. 행동 처리 중에는 중복 입력을 막기 위해 아이템과 메뉴 버튼이 잠시 비활성화됩니다.

**구명보트 탈출의 준비와 실패 위험** — `해결할 과제`의 `일기에서 탈출방법 찾아보기`를 완료하면 간조 때 암초에서 구명보트를 발견할 수 있습니다. 하지만 발견만으로 탈출하지는 않습니다. 밧줄+돛천 또는 밧줄+판자로 선체를 수리하고, 암초·해안에서 노를 찾고, 구명보트 발견 후 절벽에서 해류와 항로를 파악해야 합니다. 준비 없이 출항하면 선체 누수, 노 없이 암초 충돌, 해류 오판, 폭풍·큰 파도에 의한 출항 실패가 발생할 수 있으며 체력·수분·정신력과 점수를 잃습니다. 폭풍 중에는 준비를 마쳐도 출항이 실패할 수 있고, 노가 부러지거나 바다로 사라질 수 있습니다. 체력 40·포만 20·수분 20 이상, 간조 및 적절한 날씨를 확인한 뒤 시도하는 것이 안전합니다. 발견한 구명보트는 암초 진입 지점 가까운 비교적 평탄한 해안(x=30, z=16)의 3D 월드에 전체 선체가 드러나도록 배치되며, 장소 이동이나 저장 불러오기로 사라지지 않습니다. 소지품에 `노`가 있을 때만 구명보트 위에 노가 표시되고, 출항 실패로 노를 잃으면 3D 화면에서도 함께 사라집니다.

**뗏목 탈출의 단계와 실패 시나리오** — 대나무·판자·밧줄·돛천을 모아 먼저 뗏목을 제작한 뒤, 별도의 행동으로 출항을 시도합니다. 출항 성공률은 난이도, 직업, 날씨, 물때, 체력·포만·수분, 절벽에서 지형을 파악했는지에 따라 달라집니다. 폭풍에서는 출항이 자동으로 실패하며, 다른 날씨에서도 파도에 전복될 뻔하거나 바람에 해안으로 밀려나거나 해류를 잘못 만나 돌아올 수 있습니다. 실패하면 체력·수분·정신력과 위기 대처 점수가 줄고, 일부 사고는 뗏목을 손상시킵니다. 손상된 뗏목은 밧줄·돛천·판자로 보강하거나 해변 표류물과 덩굴로 수리해야 합니다. 완성된 뗏목은 해변 가장자리의 3D 월드에 실제 모델로 배치되고, 다른 장소로 이동하거나 저장을 불러와도 유지됩니다. 출항 실패로 손상된 경우 3D 모델에도 느슨해진 판자와 돛의 파손 흔적이 표시됩니다. 하루에 출항은 한 번만 시도할 수 있으며, 다음 날 다시 시도할 수 있습니다.

**행동 메뉴와 이야기 패널** — 행동 또는 이동 선택지를 누른 직후에도 현재 메뉴를 화면에 남겨 둡니다. 처리 중에는 중복 선택을 막기 위해 메뉴를 잠그며, 이야기 패널의 로그가 새 이벤트를 받아 스크롤됩니다. 다음 선택지가 도착하면 메뉴가 갱신됩니다.

**밀림의 수분 보충 이벤트** — 밀림 재방문 상황 설명에서 실제로 물 흐르는 소리가 들렸을 때만 `물소리를 따라 샘을 찾는다` 메뉴가 나타납니다. 70% 확률로 맑은 샘물을 발견해 수분 28과 정신 2를 회복하고, 20% 확률로 잎사귀에 고인 빗물을 찾아 수분 14를 회복합니다. 나머지 10%에는 물을 찾지 못하며, 다음 날 다시 시도할 수 있습니다. 물소리 단서는 이번 밀림 방문의 설명에만 유효하며, 소리 묘사가 없으면 관련 메뉴를 표시하지 않습니다. 행동에 따른 기본 수분 소모는 회복량에서 별도로 차감됩니다.

**장소별 나뭇가지·풀잎 텐트형 은신처와 보강** — 해변·밀림·암초·동굴·절벽 모두에서 은신처를 지을 수 있습니다. 완성 후 2단계까지 보강할 수 있습니다. 1단계는 굵은 지지대와 촘촘한 풀잎 지붕으로 비바람을 더 잘 견디게 하고, 2단계는 마른 잎 침상과 옆면 바람막이로 수면과 회복을 개선합니다. 기본 은신처는 밤마다 체력 +7·정신 +5, 1단계는 +9·+6, 2단계는 +10·+7을 회복합니다. 비가 내릴 때의 수분 회복도 각각 +18, +21, +24이며, 2단계 은신처에서는 상태이상이 밤마다 3일씩 줄어듭니다. 각 장소의 보강 상태는 저장되며 3D 화면에서 추가 지지대와 침상으로 표현됩니다. 보강 2단계를 마치면 메뉴는 반복 보강 대신 `은신처를 손질한다`로 바뀝니다. 이전 버전 저장 파일에 이미 완성된 은신처가 있으면 기존 위치인 밀림의 은신처로 이전됩니다.

**장소별 환경 위협 이벤트** — 해변에서는 이안류에 휩쓸리거나 해파리에 쏘이고, 밀림에서는 벌떼와 가시덩굴, 암초에서는 미끄러운 바위와 만조 파도, 동굴에서는 갑자기 날아드는 박쥐 떼, 절벽에서는 돌풍에 넘어지는 사고가 발생할 수 있습니다. 사고는 체력과 정신력을 함께 낮추며, 일부는 수분 감소나 부상 상태이상도 유발합니다. 각 장소의 위험 판정은 하루 한 번으로 제한해 같은 장소를 반복 방문하며 피해가 연속 발생하는 것을 막습니다. 보통 난이도의 기본 발생률은 장소에 따라 약 14~16%이며, 암초 만조 시와 폭풍 속 절벽에서는 확률이 높아집니다. 쉬움은 위험 확률이 낮고 하드코어는 높으며, 탐험가와 생존 전문가는 약간의 이점을 얻습니다. 위험을 감수해 탐험할지, 먼저 은신처·치료·자원을 준비할지 판단하는 것이 중요합니다.

**체력·정신력 회복 경로 다양화 및 밸런스** — 회복은 한 가지 행동을 반복해 수치를 쉽게 채우지 못하도록 대부분 장소별 하루 한 번으로 제한하고, 행동력과 포만·수분 비용을 유지합니다. 해변의 그늘 휴식은 체력 +7·정신 +5, 밀림 그늘에서의 호흡과 상처 점검은 +6·+4, 암초의 안전한 바위 뒤 휴식은 물때에 따라 체력 +2~4·정신 +3~5, 동굴 휴식은 +9·+5를 회복합니다. 절벽의 반복적인 수평선 관찰은 하루 한 번 정신 +3이며, 첫 지형 파악이나 구명보트 항로 확인 보상은 별도로 유지됩니다. 기도는 하루 한 번 정신 +6~10(첫 기도만 추가 +4), 모닥불은 하루 한 번 정신 +5를 회복합니다. 은신처는 밤마다 기존 단계별 회복 효과를 주며, 구급상자는 체력 +20·정신 +4를 회복하고 행동력을 소모합니다. 물병과 유리병은 수분 회복이 주 목적이므로 체력 회복은 각각 +3·+2로 낮췄고, 밀림 과일과 물고기의 체력 회복은 각각 +5입니다. 은신처를 새로 지을 때의 정신 회복도 +8로 조정했습니다. 하루 제한 플래그는 다음 날 시작 시 초기화됩니다.

**실시간 소모** — 낮 동안 실제 플레이 시간이 길어질 때 포만·수분·정신·체력이 완만하게 줄어듭니다(보통 난이도 기준 대략 포만 60초, 수분 45초, 정신 120초, 체력 180초마다 1). 이야기 읽기와 선택 시간에 지나친 손실이 나지 않도록 조정했습니다. 난이도·직업의 소모 배율이 적용되고, 체력·정신은 시간만으로는 1 아래로 내려가지 않습니다. `game-core.js`의 `LIVE_RATE_SEC`에서 조절합니다.


**난이도별 최종 생존 판정** — 구조·탈출 엔딩이 먼저 발생하지 않았다면 목표 날짜 시작 시 최종 생존 여부를 판정합니다. 쉬움은 16일째, 보통은 14일째, 하드코어는 12일째입니다. 체력 35 이상이고 은신처를 건설했으면 `섬의 주민`, 그 외에는 `사라짐` 엔딩으로 이어집니다.

**판정일 밸런스 검증** — 각 판정 후보일과 난이도 조합별로 무작위 선택 플레이 300판 및 생존 관리 전략 플레이 300판을 비교했습니다. 선택한 시점(쉬움 16일·보통 14일·하드코어 12일)에서 무작위 선택 플레이의 `섬의 주민` 엔딩 비율은 각각 약 21%, 24%, 24%였고, 관리 전략 플레이는 세 난이도 모두 판정 시점까지 도달했습니다. 따라서 숙련도에 따른 차이는 유지하면서 난이도별 최종 성공 기회가 크게 벌어지지 않도록 설정했습니다. 이는 자동 시뮬레이션 결과이며 실제 사람의 플레이 성공률을 보장하지는 않습니다.


**동굴 먹거리 탐색 및 반복 휴식 문구 (수정본 39)** — 동굴에서 하루 한 번 `동굴에서 먹거리를 찾는다`를 선택하면 식용 버섯, 고사리, 가재 또는 새우를 발견할 수 있습니다. 탐색은 포만 2·수분 3을 소모하며, 운이 없으면 먹거리를 찾지 못할 수 있습니다. 발견한 음식은 왼쪽 소지품에서 직접 클릭해 먹습니다. 버섯은 포만 +12·정신 +1, 고사리는 포만 +14·체력 +1·정신 +1, 가재는 포만 +22·체력 +2, 새우는 포만 +18·체력 +1을 회복합니다. 불을 피우지 못한 상태에서 가재나 새우를 날것으로 먹으면 낮은 확률로 복통이 발생합니다. 하루 탐색 제한은 다음 날 초기화됩니다. 휴식을 이미 사용한 장소의 메뉴와 이야기 안내는 `잠시 더 휴식`으로 표시합니다.

**포만·수분 이벤트 밸런스** — 하루 경과 소모(포만 5·수분 5)와 행동 기본 소모(포만 약 1·수분 2)는 유지하되, 이벤트 한 번으로 게이지가 지나치게 크게 회복되거나 무거운 행동의 소모가 중복되는 경우를 조정했습니다. 밀림 과일은 포만 +24·수분 +8, 물소리 탐색은 수분 +28(70%) 또는 +14(20%), 동굴 민물은 수분 +30, 깊은 동굴 물은 +14로 조정했습니다. 물병은 +35, 유리병은 +28, 바나나는 포만 +20이며, 은신처의 빗물 이벤트는 수분 +18, 집수기 이슬은 매일 +8입니다. 물고기는 도구·직업·물때에 따라 포만 +28~46, 조개는 간조 +24·만조 +14를 회복합니다. 멧돼지에게서 떨어진 바나나는 실제로 먹을 때 포만이 회복되도록 바꿨습니다. 탐색·제작·이동에서 부과되는 추가 포만·수분 비용도 일부 낮췄지만, 행동 기본 소모와 자원 고갈 페널티는 유지했습니다.

**난이도별 시작 능력치** — 체력·정신력이 최고치로 시작하지 않고 중간 수준에서 시작합니다. 쉬움은 체력 72~82·정신 65~75, 보통은 체력 60~70·정신 50~60, 하드코어는 체력 45~55·정신 40~50 범위에서 무작위로 결정됩니다. 선원·탐험가·조종사 등의 직업 보너스가 시작 수치를 추가로 보정할 수 있습니다. 포만·수분은 기존 범위를 유지하며, 난이도별 소모 배율은 계속 적용됩니다.

**생존 수치 밸런스** — 시작 시 포만·수분의 최저값을 소폭 높이고, 하루 경과 소모를 포만·수분 각 5, 정신 1~2로 조정했습니다. 은신처 없이 밤을 보낼 때는 체력·정신 각 4를 잃습니다. 기본 은신처는 밤마다 체력 +7·정신 +5, 1단계 보강은 +9·+6, 2단계 보강은 +10·+7을 회복합니다. 1단계 이상은 상처와 오한의 야간 부담을 줄이고, 2단계는 상태이상의 회복 속도를 높입니다. 부상·복통·열병의 하루 피해도 낮췄습니다. 같은 날 반복 방문으로 피해가 연속 누적되지 않도록 폭풍 피해, 만조 파도 피해, 멧돼지 조우는 각각 하루 한 번으로 제한합니다.

선택지(행동 메뉴)는 아래쪽 이야기 패널의 버튼으로 고릅니다. 왼쪽 `정보 패널`에는 미니맵·해결할 과제·소지품(2열)·상태이상이 있습니다. 뗏목 재료의 획득 장소는 소지품의 `생존 수첩`을 눌러 확인합니다.

## 어떻게 동작하나 (단계별)

1. **분석**: 기존 구조는 `game-core.js`(규칙)가 `emit()`으로 이벤트(`line`, `state`, `choices`, `setup`, `ending` …)를 내보내고 브라우저는 화면에 그리는 형태입니다. 규칙과 표시를 분리한 구조를 유지하며, 시작 전 설정과 은신처의 3D 표현에 필요한 이벤트·상태 전달을 추가했습니다.
2. **3D 월드(`world.js`)**: 높이 함수 `heightAt(x, z)` 하나가 섬 전체(해변·밀림 언덕·북쪽 산=절벽·서쪽 바위산=동굴·동쪽 암초)를 정의합니다. 지형 메시, 이동 가능 판정, 길(흙길 리본), 나무·바위 배치가 모두 이 함수를 기준으로 만들어집니다. 나무와 바위는 `InstancedMesh`로 한 번에 그립니다.
3. **장소 = 3D 표식**: 해변·밀림·암초·동굴·절벽이 각각 좌표(`PLACES`)와 링·빛기둥·이름표를 가집니다. 서버가 "이동 가능한 곳"을 알려 주면 해당 표식이 주황색으로 빛나고 화면 가장자리에 웨이포인트가 뜹니다. 발견 전의 동굴·절벽은 `???`로 표시됩니다.
4. **이동과 상호작용**: 플레이어는 3D 공간을 자유롭게 걸을 수 있고(물이 깊은 곳은 막힘), 이동 가능한 표식에 닿거나(E) 클릭하면 `{type:"map", place}`를 서버로 보냅니다. 서버가 이동을 승인하면 `state.place`가 바뀌고, 아바타가 길을 따라 새 장소까지 **자동으로 걸어갑니다**. 이동 규칙(허기·갈증 소모, 이벤트)은 전부 서버가 결정합니다.
5. **연출은 상태의 반영일 뿐**: `phase`(낮/밤), `weather`, `low`(간조/만조), `fx.fire`, `fx.boar`, `fx.shelter`, `shelters`, `shelterUpgrades`, `raft`, `raftDamaged`, `lifeboatFound`, `lifeboatHasOars`가 오면 하늘 색·안개·달빛·별·비·번개, 수위, 모닥불(불빛·불티), 멧돼지 조우와 장소별로 완성된 은신처가 반영됩니다. `shelters` 배열은 섬 위에 실제로 세운 은신처의 장소 목록이며, 각 은신처는 나뭇가지 골조에 풀잎을 겹쳐 엮은 원시 A형 텐트 형태로, 완성된 뗏목과 함께 3D 화면에 계속 표시됩니다. 보강 단계에 따라 추가 지지대와 마른 잎 침상이 더해집니다. `raft`는 제작 여부를, `raftDamaged`는 출항 실패로 인한 손상 여부를 나타냅니다. `lifeboatFound`는 구명보트 발견 여부를, `lifeboatHasOars`는 소지품의 노 보유 여부를 나타냅니다. 발견 후 구명보트 모델은 암초 진입 지점 가까운 평탄한 해안에 유지되며, 노 모델은 실제 노 소지 여부에 따라 켜지거나 꺼집니다. 카메라와 플레이어 사이를 가리는 나뭇잎은 자동으로 사라집니다.
6. **시점**: `player.js`의 카메라 리그가 3인칭/탑뷰/1인칭/궤도(타이틀·결말)를 담당합니다. 플레이 중에는 이야기 패널이 가리는 만큼 장면을 위로 밀어 올립니다.

## 장소·연출을 추가하려면

- 새 장소: 서버 `game-core.js`에 장면을 추가하고, `world.js`의 `PLACES`/`LINKS`와 지형 함수에 좌표를 더하면 표식·길·웨이포인트가 자동으로 생깁니다.
- 새 날씨/시간대: `world.js`의 `ENV_SRC`에 하늘·안개·조명 값을 추가합니다.
- 디버그: 주소 뒤에 `?debug`를 붙이면 콘솔에서 `window.__island`로 월드/플레이어를 조작해 볼 수 있습니다.

**추위 대응 다양화와 멧돼지 위험 조정 (수정본 35)** — 은신처가 없고 맑지 않은 밤에 추위 이벤트가 발생하면 상황에 맞춰 대응할 수 있습니다. 성냥이 있고 비바람이 심하지 않거나 동굴 안이면 작은 임시 모닥불을 피울 수 있습니다. 밤중 임시 불씨는 체력·정신력을 각각 +2 회복하지만 포만·수분을 각각 2 소모하고, 일반 모닥불보다 회복량이 작습니다. 낮에 준비한 모닥불의 기존 야간 회복(체력 +6·정신 +5)은 유지되며, 불 가까이에서 감기 지속 기간을 조금 줄일 수 있습니다. 마른 잎과 풀을 겹쳐 보온하는 방법은 밀림·동굴에서 성공률이 높고 폭풍이나 절벽에서는 낮습니다. 바위 그늘을 찾는 방법도 장소별 성공률이 다르며, 동굴이 가장 유리하고 절벽이 가장 불리합니다. 마지막으로 제자리걸음으로 체온을 유지할 수 있지만 체력·포만·수분을 더 소모합니다. 실패한 보온 시도는 체력·정신력 손실과 감기를 유발할 수 있습니다. 은신처·모닥불이 있거나 맑은 밤이면 별도 한기 선택지는 나타나지 않습니다.

**멧돼지 피해와 점수 표시** — 멧돼지에게 들이받히거나 맞서 싸우다 다치거나 나무를 오르다 실패하면 체력·정신력 손실이 기존보다 커집니다. 심한 경우 체력 약 19~21, 정신력 약 10~12까지 즉시 감소할 수 있고 부상도 발생할 수 있으므로 무기·회피 선택이 중요합니다. 멧돼지를 피하거나 쫓아낸 보상 점수는 내부 점수에 계속 반영되지만, 점수 가산·감산 문구와 숫자 결과는 이야기 패널에 표시하지 않습니다. 실제 부상·공포는 상황 묘사와 왼쪽 HUD 수치로 확인합니다.

## 알아둘 점

- 게임 규칙·확률·아직 보지 않은 장면의 문장은 서버에만 있습니다(`game-core.js`는 `public/` 밖이라 요청해도 404). 이미 화면에 표시된 문장과 수치, 3D 장면 코드는 브라우저에서 볼 수 있습니다.
- 플레이어 ID는 브라우저에 저장되는 임의 문자열이라 계정이 아닙니다. 공개 서비스로 올리려면 HTTPS 프록시 뒤에서 실행하고 `data/` 폴더를 백업하세요.
- Three.js는 MIT 라이선스입니다(`public/vendor/three.LICENSE.txt`).
